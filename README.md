# Python learning projects

This repository contains two independent Python projects:

- [Python for Java Developers](./chap01_to_15/README.md) — 15 standalone lessons, with a roadmap for continuing into data science and LLMs.
- [NSE Alerter](./nse_alerter/README.md) — a market-signal alert application with its own dependencies, configuration, and tests.

Open `python_for_java_devs.code-workspace` to work with both projects in one VS Code window. Each project can also be opened and run from its own folder.

The GitHub Actions workflows in `.github/workflows/` run and maintain the NSE Alerter project.
